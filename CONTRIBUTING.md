# Contributing

Terima kasih atas minat Anda berkontribusi pada proyek ini.

## Cara berkontribusi

1. Fork repository ini.
2. Buat branch fitur: git checkout -b feature/nama-fitur.
3. Lakukan perubahan, lalu jalankan pengujian yang tersedia.
4. Commit dengan pesan yang jelas: git commit -m "feat: tambahkan fitur X".
5. Push ke branch Anda: git push origin feature/nama-fitur.
6. Buat Pull Request dan jelaskan perubahan Anda.

## Pedoman

- Gunakan bahasa Indonesia atau bahasa Inggris yang konsisten.
- Sertakan deskripsi dan contoh penggunaan untuk fitur baru.
- Perbarui README bila Anda mengubah antarmuka atau perilaku.
- Hindari memasukkan kredensial, token, atau file .env ke dalam commit.
- Hormati kode etik yang ada di [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Melaporkan bug

Gunakan tab Issues dan sertakan langkah reproduksi, hasil yang diharapkan, serta hasil aktual.
