# Security Policy

## Versi yang didukung

Repository ini adalah proyek pribadi/eksperimen. Pembaruan keamanan diberikan pada commit terbaru di branch utama.

## Melaporkan kerentanan

Jangan membuka issue publik untuk kerentanan keamanan. Kirim laporan melalui:

- GitHub Security Advisory (tombol "Report a vulnerability" di tab Security), atau
- Email: aryafatthurahman4@gmail.com

Sertakan deskripsi masalah, dampak, langkah reproduksi, dan saran perbaikan bila ada.

## Praktik keamanan dalam proyek

- File .env, .env.production, dan kredensial lainnya tidak pernah di-commit.
- Gunakan variabel lingkungan untuk konfigurasi sensitif.
- Dependensi sebaiknya diperbarui secara berkala.
