## Overview

Simulasi rangkaian Arduino dan ESP32 menggunakan Wokwi. Repositori ini merupakan bagian dari koleksi proyek Arya Fatthurahman di bidang AI Engineering, Software, Data, dan Cloud.

## Features

- Simulasi rangkaian Arduino/ESP32
- Diagram Wokwi (diagram.json)
- Sketch siap diunggah ke simulator

## Project Structure

```text
Wokwi/
|-- .gitignore
|-- diagram.json
|-- sketch.ino
```
